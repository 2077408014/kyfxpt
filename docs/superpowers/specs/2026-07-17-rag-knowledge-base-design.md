# RAG知识库问答系统设计文档

## 1. 概述

本文档设计一个基于RAG（检索增强生成）架构的知识库问答系统，集成到现有考研学习平台中。系统实现知识库优先回答机制，确保AI在回答问题时优先检索并使用知识库内容。

## 4. 核心模块设计

### 4.1 数据源预处理模块

**功能**：实现OCR识别与文本清洗，支持普通PDF、扫描PDF及图片文档

**输入**：文件路径（支持 .pdf, .png, .jpg, .jpeg, .doc, .docx, .txt）

**输出**：清洗后的纯文本内容

**实现逻辑**：
1. 根据文件类型选择解析方式
   - 普通PDF → PyPDF2提取文本
   - 扫描PDF → 转换为图片 → OCR识别
   - 图片 → OCR识别
   - DOC/DOCX → python-docx提取文本
   - TXT → 直接读取

2. 文本清洗规则
   - 去除多余空白字符
   - 去除无意义的乱码和噪声
   - 合并断行的句子
   - 保留标题和列表结构

### 4.2 文本分块模块

**功能**：采用滑动窗口分块策略，解决长文本语义断裂问题

**参数配置**：
- 块大小：300~500字符
- 重叠大小：50字符
- 分隔符优先级：段落 > 句子 > 换行 > 空白

**实现逻辑**：
1. 使用LangChain的RecursiveCharacterTextSplitter
2. 按段落优先分割，保持语义完整性
3. 重叠部分确保上下文连续性
4. 每个块附带元数据（文件名、块序号、原始位置）

### 4.3 向量化与向量存储模块

**功能**：实现文本向量化及FAISS向量库存储

**实现逻辑**：
1. 使用sentence-transformers的all-MiniLM-L6-v2模型
2. 批量向量化文本块
3. 创建FAISS索引（IndexFlatL2）
4. 存储索引到磁盘（faiss_index/目录）
5. 保存文档元数据映射

**索引结构**：
```
faiss_index/
├── index.faiss          # FAISS索引文件
├── index.pkl            # 文档元数据映射
└── metadata.json        # 索引元信息（创建时间、文档列表）
```

### 4.4 检索增强生成问答模块

**功能**：实现问题向量化、相似度检索、Prompt拼接及LLM生成

**核心流程**：
1. **问题向量化**：将用户问题转换为向量
2. **相似度检索**：在FAISS索引中查找Top-K最相似的文档块
3. **相关性判断**：计算相似度阈值，判断是否有相关内容
4. **Prompt拼接**：将检索到的文档内容与问题拼接成Prompt
5. **LLM生成**：调用本地LLM生成回答
6. **来源标注**：标注回答引用的文档来源

**知识库优先机制**：
- 当相似度高于阈值（如0.3）时，基于知识库内容回答
- 当相似度低于阈值时，明确提示用户该问题超出知识库范围
- 当知识库为空时，直接调用LLM回答

**Prompt模板**：
```
你是一个专业的考研复习助手。请根据以下提供的知识库内容回答用户的问题。

知识库内容：
{context}

用户问题：{question}

回答要求：
1. 必须基于知识库内容回答，不得编造信息
2. 如果知识库中没有相关内容，请明确说明"该问题超出知识库范围"
3. 如果知识库内容不足，请结合你的知识补充，但要注明"补充信息"
4. 回答要简洁明了，使用markdown格式
5. 在回答末尾标注来源文档名称
```

## 5. API设计

### 5.1 资料管理接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/rag/upload` | POST | 上传文档到知识库 |
| `/api/rag/documents` | GET | 获取知识库文档列表 |
| `/api/rag/documents/{id}` | DELETE | 删除知识库文档 |
| `/api/rag/knowledge/status` | GET | 获取知识库状态 |

### 5.2 问答接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/rag/chat` | POST | RAG问答（知识库优先） |
| `/api/rag/search` | POST | 仅检索知识库（不生成回答） |

### 5.3 接口详细设计

#### POST /api/rag/upload

**请求体**：
```json
{
  "file": "multipart/form-data"
}
```

**响应**：
```json
{
  "success": true,
  "message": "文档上传并索引成功",
  "document_id": 1,
  "filename": "考研政治知识点.pdf",
  "chunk_count": 45,
  "index_time": 3.2
}
```

#### POST /api/rag/chat

**请求体**：
```json
{
  "question": "什么是辩证唯物主义？",
  "top_k": 3,
  "similarity_threshold": 0.3
}
```

**响应**：
```json
{
  "answer": "辩证唯物主义是马克思主义哲学的重要组成部分...",
  "source": "考研政治知识点.pdf",
  "relevant_chunks": [
    {
      "content": "辩证唯物主义认为物质是第一性的...",
      "similarity": 0.85,
      "source": "考研政治知识点.pdf"
    }
  ],
  "from_knowledge_base": true
}
```

## 6. 数据库模型设计

### 6.1 KnowledgeDocument模型

```python
class KnowledgeDocument(Base):
    __tablename__ = "knowledge_documents"
    
    id = Column(Integer, primary_key=True, index=True)
    user_id = Column(Integer, ForeignKey("users.id"))
    filename = Column(String(255))
    file_type = Column(String(20))
    file_size = Column(Integer)
    storage_path = Column(String(500))
    chunk_count = Column(Integer, default=0)
    indexed_at = Column(DateTime)
    created_at = Column(DateTime, default=datetime.utcnow)
```
